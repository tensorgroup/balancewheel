# Handoff — 2026-10-25: `bw guard` v0 (autonomy, the broker, review, verification)

*Session record (point-in-time; the guard spec, the README, and the CHANGELOG own the facts).*

## What changed

- **Autonomy per lead** (config schema 3): `native` (Claude Code `--permission-mode auto`,
  Codex `--approve-for-me`), `guard`, `bypass`, `manual`. Schema 3 moves Codex leads to
  `--approve-for-me` by default; a schema-2 file keeps today's argv.
- **A rules-only guard, in shadow, for pi:** a broker inside `bw lead` (`lead/guard/`) that a
  thin pi extension asks over a socket no lead can write. It logs what it would decide and
  allows everything. `bw guard review` audits stops and sampled allows; `bw guard verify pi`
  runs the attack (`tests/attack/guard_attack.sh`) and records a pass; `bw status` gets
  `guard:` lines; `bw lead` exits 7 when a guarded lead cannot start.
- **agy's guard is built but refused** until its hook spike runs: `bw guard install agy` and
  `bw guard verify agy` refuse with the same reason, and the example config sets the agy
  lead to `manual`.
- **Docs:** a "Amendments from the v0 build" section in the guard spec (twelve named
  decisions), an amendment in the 2026-10-24 spec, README, architecture, stack, orca,
  CHANGELOG, CLAUDE.md.

## Issues that cost time

- **Firmlinks and symlinks:** macOS paths that differ by `/private` or a firmlink made
  "inside the worktree" checks and state-dir overlap checks disagree; and a glob followed a
  symlink out of the tree.
- **Nested repos:** `git -C <dir>` and script trust had to be decided per repository, not per
  worktree.
- **The marker FIFO and the one-shot self-test marker:** the start-time self-test replayed
  its marker and counted as a real call until it was made one-shot, disarmed before the lead
  starts, and excluded from evidence. The broker also needed a `pause()` so no thread exists
  while `preexec_fn` runs.
- **Vacuous attack passes:** early attack cases passed without proof the lead tried the
  call, or that the OS (not the model) refused the socket replacement. The judge now needs
  disk evidence per case, and a case the lead never attempts fails the run.
- **Model refusals in the attack:** models declined repeated or tampering calls; the
  replacement case is attempted by a plain process under the same sandbox flags, and the
  resumed phase varies the call.
- **pi via OpenRouter needs the `openrouter/` prefix** on the model id.
- **Usage caps:** the Google plan behind agy was capped for the whole session.

## Deliberately left alone

- agy spike 1b (hook behaviour on the installed agy) did not run; agy's normaliser maps every
  payload to `other` and no agy fixtures exist.
- No model judge, no acting, no `rules_on_native`, no `guard.jsonl` retention.
- Minor findings from the per-task reviews are tracked in the build ledger for the final
  review, not fixed here.
- The Claude Code and Codex native flags were not launched interactively.
